# Hasp

A vault for API keys, backup codes and one-time codes, with a browser extension, a web dashboard, a desktop app and a mobile app.

This repository currently holds the design exploration and the implementation plan. No product code yet.

- `mockups/index.html` lists six visual directions.
- `mockups/gallery.html` shows all 36 rendered mockup images.
- `mockups/png/` holds the images.
- `PLAN.md` covers architecture, crypto, imports, security and phases.

Sample vault data appears throughout. All keys are invented.
