Six directions
for one vault

Hasp stores API keys, backup codes and one-time codes for people who already keep them in notes. It has four surfaces: a browser extension, a web dashboard, a desktop app and a mobile app. Each direction below applies one visual system to all four, using the same sample vault so the comparison stays honest.

Direction 02 applied to three surfaces. Every direction carries the full set of six screens.

The six

Pick one. Details inside each.

  • 01 Foundry Parts catalog. Dense table, stamped labels, oxide accent. Archivo, square corners. Open
  • 02 Reading Room Index of records. Serif titles, hairline rules, pine accent. Notes keep their wording. Open
  • 03 Flight Deck Operations console. Dark, dense, semantic signals. Amber for live keys, teal for staging. Open
  • 04 Grid Swiss sheet. Visible structure, hard rules, one ultramarine accent. Instrument Sans. Open
  • 05 Native Chromeless utility. System type, icon rail, keyboard first. Feels local, not like a site. Open
  • 06 Halcyon Consumer vault. Warm paper, soft cards, juniper accent. Reads well on a phone first. Open
